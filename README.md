## 🚀 Key Interactive Features

1. **Live CAD Canvas Background**: Animated conduit paths and circuit traces representing continuous mechanical, electrical, and plumbing flows.
2. **Interactive BIM Discipline Console**: Filter or isolate Mechanical (Blue), Electrical (Yellow), Plumbing (Green), and Fire Safety (Red) or view the integrated multi-disciplinary overlay.
3. **Interactive 2.5D BIM Clash Detection Sandbox**: Demonstrates Bhushan's constructability review workflow. Visitors can toggle ductwork, cable ladders, fire sprinkler lines, and drainage pipes, trigger clash detection, and apply spatial reroutes to eliminate clashes.
4. **Key Project Portfolio Showcase**: Filterable gallery of Google & Apple Data Centers, CIDCO ₹4,256 Cr Mega Mass Housing, BDD Chawl 67-floor towers, TCS Olympus, and DRFMS Hospital with technical deep-dive modals.
5. **Interactive Career Timeline**: 8 career milestones (Turner International, Blue Star, Sandeep Shikre & Associates, Fitech Systems, Urban Transit Monorail) highlighting verified metrics (20% clash reduction, ₹15L rework prevented, ₹50 Cr tender bids).
6. **Interactive BOQ & Takeoff Estimator Widget**: Preliminary capacity and budget estimation calculator for Data Centers, Townships, Commercial Towers, and Hospitals.
7. **vCard Generator & Resume PDF Engine**: One-click vCard download and an executive print layout (`Ctrl+P` or "Print Resume" button) that generates a clean paper resume without website clutter.

## 🌐 How to Deploy to GitHub Pages (Step-by-Step)

### Option A: Using Git Command Line
1. Open terminal inside this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Bhushan Arvind Patil MEP Interactive Portfolio"
   git branch -M main
   ```
2. Create a new repository on GitHub (e.g. `bhushan-mep-portfolio` or `<your-username>.github.io`).
3. Link and push:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
4. On GitHub, go to **Settings** &rarr; **Pages** &rarr; under **Branch**, select `main` and `/ (root)` &rarr; click **Save**.
5. Your website will be live at `https://<your-username>.github.io/<your-repo-name>/`!

### Option B: Upload via GitHub Web Interface
1. Create a new repository on [github.com](https://github.com).
2. Drag and drop `index.html`, `css/`, `js/`, and `README.md` into the repository.
3. Go to **Settings** &rarr; **Pages** &rarr; Set source to `main` branch &rarr; Click **Save**.
